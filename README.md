# 💸 Expense Tracker App

A full-stack application that allows users to track their daily expenses, categorize spending, and visualize their financial activity.

## 🧰 Tech Stack

### Backend
- **Spring Boot** (Java)
- **Spring Data JPA**
- **Hibernate**
- **MySQL**

### Frontend
- **React**
- **Bootstrap / Custom CSS**
- **Axios**

## 📦 Features

- Add, update, and delete expenses
- Assign multiple categories to each expense
- View expenses in a list or tabular format
- Date-based filtering
- Form validation for inputs
- Automatically assigns the current date to new expenses
- Responsive and user-friendly UI
